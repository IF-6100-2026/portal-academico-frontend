# Portal Académico — Frontend

Equipo actual: Josué Delgado Corrales y Sebastián Cordero Quesada.

Repositorio local preparado para el frontend del proyecto de IF-6100. Los prototipos HTML y sus imágenes del PC1 se conservan íntegros en `prototipos/` del repositorio de documentación. No son todavía una aplicación React integrada.

Para el PC2 está pendiente preparar React con TypeScript y Vite, un módulo tipado de acceso a la API y una pantalla que muestre la respuesta del endpoint de prueba del backend. También quedan pendientes los lineamientos y la guía de ambiente.

Este repositorio por ahora contiene únicamente la preparación inicial; no es una aplicación ejecutable ni una entrega terminada. El destino solicitado es `IF-6100-2026`, pendiente de verificar permisos y publicar.
